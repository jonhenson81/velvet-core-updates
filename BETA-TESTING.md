# Velvet Core 0.5.81-beta39 — Friend Test Guide

Thanks for helping test Velvet Core! This is an early Android beta. Please try the items below and tell us what works, what feels confusing, and anything that crashes or behaves unexpectedly.

## Before installing

- This build is for Android 11 (API 30) or newer and ARM64 devices.
- Install the APK directly over beta38 if it is already installed. **Do not uninstall the previous version**, because uninstalling removes the app's local data.
- Android will show its normal installation confirmation. Review it and choose whether to install.

## Tests

1. **Chat experience**
   - Open a companion's Chat screen.
   - Send a few ordinary messages.
   - Check the chat layout, keyboard visibility, and navigation in and out of the conversation.

2. **Companion-specific learning**
   - Tell one companion a harmless preference (for example, a favorite color).
   - Tell a different companion a different preference.
   - Check whether each companion keeps its own information separate.

3. **Sensitive information safeguards**
   - Use only made-up examples. Do not enter real addresses, phone numbers, passwords, or other private information.
   - If prompted to approve saving sensitive information, check that the app asks before saving it.
   - Passwords and authentication secrets should never be saved to memory.

4. **Memory and history controls**
   - Find the controls for deleting an individual companion's memory and conversation history.
   - Check the Privacy controls for the option to delete information across all companions.
   - Do not delete anything you want to keep.

5. **Settings navigation**
   - Open Models, Diagnostics, and Voice & Speech.
   - Check that each section opens and its available options are reachable.

## What to send back

Please report:
- The phone model and Android version.
- Which tests you completed.
- Anything that did not work, including the exact screen or step.
- Any error message or crash behavior.
- What felt smooth, confusing, slow, or missing.
- Suggestions that would make the app easier or more enjoyable to use.

Screenshots are helpful, but please check that they do not show private conversations or personal information.

Thanks again for helping test Velvet Core!
